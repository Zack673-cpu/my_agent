# 绘本智能体前端重构

## 我理解的完整流程

整个应用是一个单页应用,分四个阶段,前端全程只在这一个页面里做阶段切换:

**阶段一 · 欢迎页**
- 页面居中只有三个元素:欢迎标语、模型切换(现有三个选项:自动 / 百炼 / 硅基流动)、一个"启动"按钮。
- 深色科技感风格:渐变背景、微光效果、元素间距宽松。

**阶段二 · 读取素材**
- 点启动后,欢迎页淡出,全屏只显示"正在读取文件中..."加载动画。
- 后端读取桌面两个文件夹:`桌面\背景图`(背景图(一)(二)(三),按文件名排序)和 `桌面\人物`(名为"人物"的图片)。桌面路径同时兼容 `%USERPROFILE%\Desktop` 和 OneDrive 桌面。
- 只做读取和清点;文件名绑定角色的逻辑沿用你已完成的 planner 约定。
- 读取失败(文件夹不存在/没图)时在此页给出明确提示并允许返回。

**阶段三 · 生成控制台(Qoder 风格)**
- 顶部显示总进度(如"第 1 / 3 张"),中间是纵向步骤时间线,元素间留足呼吸感。
- 循环逻辑:对每一张背景图依次执行——
  1. 前端弹出询问卡片:"这一张生成真人还是卡通?",两个按钮确认;卡片上同时提供一个可选的自定义提示词文本框,用户可以填写这一张的额外要求(如"躲在树后探出头"),留空也可以;
  2. 确认后,后端拿"这张背景图 + 人物图"跑精简智能体流程:感知(看图提特征) → 规划(自动写提示词) → 出图,不做自检重试;
  3. 每个步骤的状态(运行中/完成 + 一句摘要)通过 SSE 实时推送,前端时间线对应节点亮起、打勾,营造持续运行的感觉;
  4. 出图完成后缩略图暂存展示,紧接着询问下一张的任务类型;
  5. 直到所有背景图处理完毕。
- 模型在欢迎页定死,整个批次沿用;某张失败时展示错误并允许"重试这一张"或跳过。
- 用户在询问卡片里填的自定义提示词,会作为这一张的"用户白话需求"(即 run_agent_stream 的 user_request 参数)传给后端,和原来一样由规划步骤嵌入提示词模板、当作额外要求;文本框留空时,后端按任务类型自动填一句默认需求(如"让人物自然融入这张背景")。

**阶段四 · 儿童绘本展示**
- 全部生成完毕后,控制台淡出,整屏呈现一本 3D 翻页儿童绘本(CSS 3D transform 实现翻页动画)。
- 结构:封面 → 内页(生成图按顺序一页一张) → 空白页(照片不足预设页数就留空) → 封底。
- 封面和封底用预先生成的一组配套插画(同风格、成套),放在项目静态资源里。
- 点击右侧书页向后翻,点击左侧书页向前翻,带翻页动效。
- 页面向下滚动出现"重新生成"按钮,点击后回到阶段一欢迎页,本轮展示内容作废(outputs 里已保存的文件不删,只清空前端状态)。

## 具体改动

**后端(新增 app.py,FastAPI)**
- GET /:返回单页应用。
- POST /api/scan:读取桌面两个文件夹,返回排序后的背景图列表和人物图路径。
- GET /api/generate(SSE):参数为背景图序号 + 任务类型 + 模型 + 可选自定义提示词,内部复用 src/planner.py 的 run_agent_stream 并把重试次数设为 0,天然就是"感知→规划→出图"三步,逐事件推送。
- 静态托管 outputs/ 与素材图,供前端展示缩略图和绘本内页。

**前端(新增 static/ 目录:index.html + style.css + app.js,纯原生,无构建步骤)**
- 四个阶段的视图切换与过渡动画。
- 阶段三的步骤时间线组件(消费 SSE 事件)与任务类型询问卡片(含可选自定义提示词文本框)。
- 阶段四的 3D 翻书组件(封面/内页/空白页/封底,左右点击翻页)。
- 统一深色科技感视觉:留白充足、卡片圆角、柔和辉光。

**资源与配置**
- 生成一对风格统一的绘本封面 + 封底插画,存入 static/assets/。
- requirements.txt 增加 fastapi、uvicorn;gradio 依赖保留不动(不再使用)。
- 现有 src/ 五个模块全部不改动,只被新后端复用。

## 测试计划
- 桌面准备好两个素材文件夹后启动 py -3 app.py,浏览器走完完整流程:欢迎页 → 读取 → 逐张选类型生成(观察 SSE 步骤实时刷新) → 绘本翻页 → 下滑重新生成回到首页。
- 异常路径:桌面缺文件夹、背景图为空、某张生成失败时的提示与恢复。

## 假设
- 绘本内页按"封面 + 6 内页 + 封底"预设,生成图不足 6 张时后面留空(背景图 3 张时,后 3 页为空白装饰页)。
- "模型切换"指在现有三个选项(auto/百炼/硅基流动)中选择。
